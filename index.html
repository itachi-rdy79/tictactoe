How to play

• Choose a mode from the dropdown.

• 5x5 Battle: connect 4 in a row to win.

• Classic 3x3: connect 3 in a row to win.

• Connect Four: drop pieces into columns and connect 4.

• This is a static site, so it works great with GitHub Pages.

Built with HTML, CSS, and JavaScript. Easy to expand with more games later.
