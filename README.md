# GAP — Arcade Gaming Hub (Offline-First)

A fast, responsive, 100% offline browser arcade hub featuring **Tic-Tac-Toe (3×3 & 5×5)**, **Chess**, and an expanded **Wordle** experience.

## Features
- **Wordle (Expanded Edition)**: Full-sized $5 \times 6$ tile grid styled after NYT Wordle with a responsive virtual keyboard and full offline dictionary.
- **Itachi Theme Vector Art**: Custom atmospheric red mist with Sharingan moon and Itachi silhouette, accompanied by active Sharingan & Crow cell glyphs.
- **Dynamic Palette Shuffling**: Light and Dark themes dynamically sample a fresh, non-blue, non-pink, non-gold neon color (Emerald, Amber, Violet, Teal, Lime) on every browser reload.
- **Vector Illustration Controls**: Clean vector icons for Undo, Reset, and New Game actions.
- **100% Offline**: Zero external dependencies, fonts, CDNs, or remote API calls.
