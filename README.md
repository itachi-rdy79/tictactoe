# GAP — Arcade Gaming Hub (Offline-First)

A high-performance, 100% offline browser arcade hub featuring **Tic-Tac-Toe (3×3 & 5×5)**, **Chess**, and a full-size **Wordle** board[cite: 7].

## Features
- **Spacious Wordle Board**: High-contrast NYT-style $5 \times 6$ tile grid with a generous 20px gap separating it from the on-screen keyboard.
- **Dynamic Backgrounds & Palette Shuffling**:
  - **Light**: Background automatically dims to a soft pastel tint matching the reload color[cite: 7].
  - **Dark**: Solid pure black (`#000000`) background with glowing neon controls.
  - **Itachi**: Pure SVG/CSS glowing red moon with Mangekyō Sharingan blades and ninja silhouette.
- **Idle Move Watchdog**: An alert animation nudges players if a turn takes longer than 60 seconds with the timer off.
- **100% Offline**: Zero external dependencies or network requests[cite: 7].
