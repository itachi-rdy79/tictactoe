# GAP — Arcade Deck 
Offline arcade game platform with a **Top HUD + Studio Stage** layout.

## Modes
- Tic-Tac-Toe 3x3 (2P / AI)
- Tic-Tac-Toe 5x5 (2P / AI)
- Chess (2P / AI)

## HUD Layout
- **Left:** GAP brand + game type pills
- **Center:** Opponent, Difficulty, Timer
- **Right:** Score ticker + modern theme picker

## Timer Presets
- `Off`
- `15s`
- `30s`
- `45s`
- `60s`

## Theme Picker
Visible theme selector with:
- 🌙 Dark
- ☀️ Light
- ✇ Itachi

## Features
- URL state sync
- Per-mode score persistence
- Move history + undo
- AI thinking indicator
- TTT animated win line
- Chess captured strips above/below board
- Offline-only (no backend required)

## Run
Open `index.html` in a browser.
