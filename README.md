# GAP — Pet Arcade Hub (Offline-First)

A playful, modern web arcade hub featuring **Tic-Tac-Toe (3×3 & 5×5)**, **Chess**, and **Wordle**[cite: 7]. Designed with floating glass panels, 3D tactile buttons, cute pet emoji patterns, and zero external dependencies[cite: 7].

## Features
* **4 Games Built-in**:
  * **3×3 Tic-Tac-Toe**: Minimax AI or local 2-player[cite: 7].
  * **5×5 Tic-Tac-Toe**: 4-in-a-row winning condition with depth-limited AI[cite: 7, 8].
  * **Chess**: Full piece mechanics, turn tracking, capture logs, and AI[cite: 7, 8].
  * **Pet Wordle**: 100% offline 5-letter pet-themed word guessing game with full on-screen & physical keyboard input.
* **Modern Playful UI**:
  * Floating glassmorphic capsules and islands (`backdrop-filter: blur(20px)`).
  * 3D tactile pill buttons with click-press feedback.
  * Vector pet pattern wallpaper (zero external images/fonts)[cite: 7].
  * Ocean Light, Dark Gold, and Itachi Obsidian theme switching[cite: 7, 8].
* **Turn Timer**: Integer-only countdown (Off, 30s, 60s, 90s), strictly defaulting to Off[cite: 7, 8].
* **Scoreboard**: Tracks games, streaks, and scores across all modes locally[cite: 7, 8].

## 100% Offline Guarantee
* Runs directly via `index.html` without WiFi or internet connection[cite: 7].
* Zero CDNs, zero remote fonts, and zero external trackers[cite: 7].
