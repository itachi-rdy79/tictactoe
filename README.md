# GAP — Arcade Gaming Hub (Offline-First)

A high-performance, fully offline web arcade hub featuring **Tic-Tac-Toe (3×3 & 5×5)**, **Chess**, and an expanded **Wordle** game[cite: 7]. Designed with floating glass panels, custom vector illustration buttons, and themed game pieces[cite: 7].

## Games Included
* **3×3 & 5×5 Tic-Tac-Toe**: Minimax AI or local 2-player with custom Sharingan/Crow piece mechanics in Itachi mode[cite: 7, 8].
* **Chess**: Complete piece logic, valid move highlighting, capture logs, and AI search[cite: 7, 8].
* **Wordle**: Fully offline 5-letter word game with an expanded dictionary, on-screen keyboard, and physical keyboard support[cite: 7].

## Theme Engine
* **Light**: Clean, high-contrast ocean blue palette with soft slate surfaces[cite: 7, 9].
* **Dark**: Matte slate base with neon cyan/aqua tactile control surfaces.
* **Itachi**: Deep obsidian palette with crimson glass and Sharingan/Crow piece replacements[cite: 7].

## 100% Offline Guarantee
* Runs directly via `index.html` with zero remote network calls[cite: 7].
* Zero external CDNs, fonts, or icons (pure SVG and system typography)[cite: 7].
