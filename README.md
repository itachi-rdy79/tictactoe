# Neo Arcade

A cool neon-style browser arcade made with pure HTML, CSS, and JavaScript.

## Games included
- 5x5 Tic Tac Toe Battle
- Classic 3x3 Tic Tac Toe
- Connect Four

## Features
- Works on GitHub Pages
- No backend
- No install required
- Score saving with localStorage
- Mobile-friendly and desktop-friendly
- Easy to expand with more games

## How to run locally
Just open `index.html` in your browser.

## How to publish on GitHub Pages
1. Create a GitHub repository
2. Upload these files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Go to **Settings → Pages**
4. Under **Source**, select:
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
5. Save
6. Wait a few seconds and GitHub will give you a public link

## Add more games
You can add more modes inside `script.js` by extending the `MODES` object and writing the gameplay logic for the new game.
